Four Key Shell
==============

这是一个 4K osu!mania 谱面播放器。

使用方法：
1. 双击 FourKeyShell.exe。
2. 首页进入“曲库 / 选曲”，可导入完整的 .osu 或 .osz 谱面；也可以直接拖到窗口。
3. 默认按键为 D、F、J、K；点击“设置”进入独立设置面板重新绑定。
4. 按 Esc 暂停/继续；按 R 重开当前谱面；按 F11 切换全屏。
5. 窗口中的音量滑杆和全局偏移会自动保存。
6. “速度”滑杆可调节音符下落速度（50%–200%）。
7. “最近谱面”可以快速重新打开以前导入的谱面；练习时可用 −10 秒/+10 秒跳转。
8. “导入到曲库”会把谱面和音频复制到本机用户曲库；之后可直接从“曲库”选择。
9. 演奏时会显示本次击打偏早/偏晚毫秒数和最近误差条；结束后显示 0–1,000,000 分、评价（SS/S/A/B/C/D）、早晚击统计和本地最佳成绩。
10. 判定会根据谱面 OverallDifficulty 使用 Perfect/Great/Good/OK/Meh/Miss 六档，并显示生命条。
11. “设置”中的“练习模式”开启时不会因血量归零结束；关闭后按成熟音游规则可能失败。
12. 按 Esc 暂停后会出现继续、重试、设置三个明确选项，不会只停在一行提示上。
13. 练习时可用“设起点”“设终点”反复循环一段，点击“清循环”恢复整曲播放。
14. “设置”中可以关闭判定音效；谱面附带可播放的自定义样本时会优先使用，否则使用内置的区分音效，不依赖客户额外安装文件。
15. “设置”中的“自动校准延迟”会播放节拍，按任意键 8 次即可自动保存偏移；按 Esc 可取消。
16. 曲库右上方搜索框可以按曲名、作者或文件名筛选谱面。
17. 曲库选中曲目后可完整试听，可暂停、拖动进度并切换单曲循环/列表播放；完成一局后可点“回放上一局”或按 P 查看最近一次击打，回放不计入最佳成绩。
18. 设置中的“自动演示（不计成绩）”会用正常头部、长键尾部和判定窗口完整跑一遍谱面，适合检查谱面节奏与长键分布。
19. 侧边栏可以在首页、曲库、成就/成绩和设置之间切换；结算页会单独显示评价与统计。
20. 测试版在“设置”页面可以检查 GitHub Release 更新；更新时会自动关闭、覆盖安装并重新启动。
21. 导入谱面后会提示同轨道长键重叠、同刻重复音符或空谱面等质量问题，但不会阻止你继续试听或游玩。

设置：点击“设置”进入独立设置面板，在里面改绑四条轨道、恢复默认键位或切换全屏。

发布方可以把已获授权的曲目预先放进客户包的 BundledSongs 目录，启动后会自动出现在曲库中。

支持范围：
- osu!mania 4K：Mode=3，CircleSize=4。
- 谱面文件必须能在同目录找到 AudioFilename 指向的音频。
- 支持 mp3、ogg、wav 音频。

注意：本程序不附带任何第三方歌曲。请只导入你拥有使用权的音频和谱面。

测试版更新说明：更新功能需要本机安装 GitHub CLI（gh）并完成 `gh auth login`，因为测试仓库是私有的。更新器只覆盖程序目录内的文件，不删除用户曲库和成绩。
